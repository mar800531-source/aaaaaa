# هروب عمار ياسر

لعبة ركض 3D تعمل على الهاتف والمتصفح وGitHub Pages.

## التشغيل
افتح `index.html` عبر GitHub Pages.

## المجلدات
- `models/` مخصص مستقبلًا لملفات GLB/GLTF.
- `textures/` مخصص مستقبلًا لخامات وصور البيئة.
- `sounds/` مخصص مستقبلًا للأصوات المرخّصة.

النسخة الحالية لا تحتاج إلى أي ملفات إضافية؛ Three.js يتم تحميله من CDN.
